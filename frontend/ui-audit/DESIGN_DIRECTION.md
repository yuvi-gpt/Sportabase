# Sportabase Web App — UI Direction

## Product priority

The web app in `/frontend` is the primary Sportabase product interface.

The Chrome extension remains important, but should inherit the established
Sportabase visual language after the main application direction is settled.

## Product character

Sportabase should feel like:

- a professional sports intelligence product;
- an editorial research surface;
- a compact evidence terminal;
- a product designed around information, not around AI decoration.

It should not feel like:

- a generic AI SaaS landing page;
- a neon dashboard;
- a collection of nested cards;
- a component-library demo;
- an interface where every fact becomes a pill.

## Primary design principles

### 1. Evidence before spectacle

Merit Score matters, but it should coexist with Evidence Status,
article type, corroboration and source state.

Avoid treating one glowing number as the entire product.

### 2. Reduce containers

Prefer spacing, typography, alignment and thin separators.

Use bordered surfaces only where grouping genuinely improves comprehension.

### 3. Restrained accent

Sportabase cyan/green remains part of the identity.

Use it for active states, meaningful evidence signals and key actions.

Do not apply gradients and glow to every important element.

### 4. Editorial hierarchy

Article titles, findings and evidence should read like intelligence reporting.

Small uppercase labels should be used selectively rather than on every section.

### 5. Information density with breathing room

Desktop should exploit horizontal space.

Mobile should recompose hierarchy rather than simply stacking desktop cards.

### 6. Motion communicates state

Motion is for loading, transitions, expanding evidence and meaningful status changes.

Decorative animation should be exceptional.

## Existing screenshots

The pre-redesign screenshots supplied during the frontend audit are the visual
reference for the current app.

The next iteration should be evaluated against them for:

- reduced AI/SaaS visual clichés;
- stronger information hierarchy;
- clearer Evidence versus Merit semantics;
- better desktop information density;
- improved mobile composition;
- stronger Sportabase identity.
