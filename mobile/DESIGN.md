# Sportabase Design System

## Direction

Editorial sports intelligence.

The interface should resemble a modern publication, research desk, or scouting
terminal more than an AI SaaS dashboard.

## Composition

Prefer:

- typography
- spacing
- alignment
- thin horizontal rules
- restrained surfaces
- asymmetric editorial composition
- deliberate data rows
- meaningful empty space

Avoid:

- hero beside floating tool card
- card grids for ordinary prose
- nested cards
- 20px+ rounded rectangles
- glowing borders
- colored shadows
- decorative gradients
- glassmorphism
- pill-heavy interfaces
- separate Article and Video tabs
- tiny uppercase labels everywhere

## Color

Background: #090b0a

Primary text: #f2f3ef

Secondary text: #a6ada7

Strong secondary text: #c9ceca

Rules: #2b312c

Soft rules: #1d221e

Sportabase signal green: #b5f36b

Warning: #e2b85f

Error: #e77878

Green is a signal color, not wallpaper.

## Typography

Editorial display typography may use Georgia on web and a serif fallback on
native platforms.

Interface typography uses the platform system sans.

Body copy must remain comfortably readable.

## Geometry

Default radius should be between 0 and 6 pixels.

Do not build the product from soft floating cards.

## Responsive behavior

Desktop uses the available horizontal width.

Mobile recomposes hierarchy rather than shrinking desktop components.

## Result language

Article and video results will share the same report language:

- report header
- primary signals
- evidence/reasoning
- supporting metrics

The visual system must never imply that Merit is a truth probability.
