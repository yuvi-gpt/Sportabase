Sportabase Privacy Policy

Last updated: May 12, 2026

Sportabase is a Chrome extension that analyzes sports articles when the user manually clicks the extension. It provides a TL;DR summary, article type detection, credibility score, and evidence signals.

Data We Collect

Sportabase may process the following data when the user clicks the extension on an active page:

  • The active article URL
  • The active page title
  • Visible article text extracted from the active tab
  • Local extension preferences, such as overlay size and position

How We Use Data

Article data is used only to generate the extension’s core features:

  • Article summaries
  • Article type detection, such as match report, transfer rumor, injury update, lineup news, interview, or tactical analysis
  • Credibility and merit scoring
  • Evidence signals explaining why an article received a score

Local extension preferences are stored in the browser to remember the user’s overlay layout.

Third-Party Processing

Sportabase may use third-party AI providers, such as Google Gemini, to process article text and generate summaries or analysis.

What Sportabase Does Not Do

  • Sportabase does not collect browsing history in the background.
  • Sportabase does not read pages unless the user manually clicks the extension.
  • Sportabase does not collect passwords, cookies, payment information, or private messages.
  • Sportabase does not sell user data.
  • Sportabase does not use article text for advertising.
  • Sportabase does not bypass paywalls or restricted content.

Data Retention

Raw article text from extension scans is not intentionally stored long-term. Basic server logs may exist temporarily for debugging, reliability, and abuse prevention.

Data Security

Sportabase communicates with its backend over HTTPS. Data sent to the backend is used for the extension’s analysis features.

User Control

Users control when Sportabase runs. The extension only analyzes the active page when the user clicks it.
